# 📖 Overview

**Sudoku CSP Solver** is a Python-based project that solves Sudoku puzzles using **Constraint Satisfaction Problem (CSP)** techniques.

The solver applies **backtracking search** and **constraint propagation** to efficiently solve Sudoku boards of different difficulty levels. It demonstrates practical Artificial Intelligence concepts including search algorithms, constraint reasoning, and problem solving.

The project supports multiple Sudoku puzzle datasets, allowing users to test the solver on easy, medium, hard, and very hard puzzles.
